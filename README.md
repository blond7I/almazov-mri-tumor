Проверка полосы на чужих данных (T1 с контрастом из BraTS, срезы без черепа) — **провал вне области обучения**: контур найден лишь на 17% срезов с опухолью, Dice 0.09, внешний край полосы охватывает 69% опухоли вместо 91%, фильтр входа отклонил только треть таких срезов ([`results/stage2/extras.json`](results/stage2/extras.json), `brats_band`). Вывод: в новой клинике систему сначала проверяют и перекалибровывают на её данных.

- **Перекос данных:** снимки с опухолью почти все — T1 с контрастом, а среди здоровых T1 лишь 28% (остальные T2, FLAIR и даже КТ). Специфичность на здоровых T1 — **86%** (18 из 21, ДИ ≈ 65–95%), на T2/FLAIR/КТ — 100%. Режим и плоскость размечены по описанию набора Figshare (T1c) и визуально ИИ-ассистентом, а не врачом; выборочная проверка врачом запланирована. Поэтому T2/FLAIR/КТ система теперь отклоняет как «вне области применения», а не отвечает «опухоли нет». Подробности: [`results/stage2/sequence_specificity.json`](results/stage2/sequence_specificity.json).

**Внешние проверки и что добавили после 8.11:**
- **BRISC 2025** (Fateh et al., *Scientific Data*, 2026; 6000 срезов T1, контуры проверены врачами). Каждый снимок сопоставлен с нашим разбиением (корреляция ≥ 0.98 с учётом поворотов и отражений); снимки из нашего обучения в проверке не участвуют. На 735 снимках нашего теста: тип верен в **93.7%**, Dice с контурами врачей BRISC **0.79** (глиома 0.72, менингиома 0.84, гипофиз 0.79). Наша разметка режима МРТ совпала с BRISC на 267 из 270 общих снимков. 1147 здоровых снимков BRISC, которых в наших данных нет, поделены пополам (похожие снимки — в одной половине): 518 ушли в обучение (эксперимент C), **629 отложены** — итоговая система проверяется только на них ([`brisc_normals_split.csv`](results/stage2/brisc_normals_split.csv)). Файлы: [`results/stage2/brisc_eval.json`](results/stage2/brisc_eval.json), [`brisc_map.csv`](results/stage2/brisc_map.csv).
- **Три уровня ответа о наличии**: «найдено» — только когда согласны классификатор и контур; «нужен просмотр» — согласен один; «не найдено». На 629 отложенных здоровых снимках BRISC (отказ — 89, ответ — 540): до дообучения классификатор поднимал ложную тревогу на 41 (7.6%); после дообучения на другой половине — на 7 (1.3%); «найдено» по правилу двух сигналов — **0 из 540**, «нужен просмотр» — 11 (2.0%). Здоровые теста организаторов: «найдено» 0 из 29, «нужен просмотр» 4. Опухоли (723 снимка теста, размеченные BRISC): «найдено» 98.5%, «нужен просмотр» 1.5%, без пометки — 0. Честно: правило двух сигналов без подбираемых параметров, но придумано после первой проверки на BRISC ([`tools/triage_levels.py`](tools/triage_levels.py), [`results/stage2/triage_levels.json`](results/stage2/triage_levels.json)).
- **Исследование целиком (серия DICOM)**: вкладка рабочего места — по каждому срезу вероятность опухоли и контур, диапазон срезов с находкой, оценка объёма (сумма площадей × шаг; ориентир — модели обучены на отдельных срезах), ключевой срез анализируется полным ансамблем ([`src/almazov/series.py`](src/almazov/series.py)).
- **«Куда смотрел классификатор»**: слой с тепловой картой (Grad-CAM ансамбля) и проверка «сотрём найденную область — что изменится» ([`src/almazov/explain.py`](src/almazov/explain.py)). Проверка на 561 срезе теста Figshare с масками экспертов (правила записаны до запуска): максимум карты внутри опухоли (допуск 16 пикс.) в **69.5%** [65.6–73.2] при случайном уровне 14.1% — слой оставлен (выключен по умолчанию). Но если стереть опухоль по маске эксперта, классификатор по-прежнему «видит опухоль» в **100%** срезов и называет тот же тип в 86% (для гипофиза — в 99.4%); уверенность падает в среднем на 13.7 п.п. против 0.7 п.п. в контроле. Вывод: классификатор опирается и на контекст среза (уровень, окружение, масс-эффект) — поэтому место опухоли даёт только сегментатор, тип — справочно, а «найдено» — при согласии обоих сигналов ([`results/stage2/explain_check.json`](results/stage2/explain_check.json), [`explain_examples.png`](results/stage2/explain_examples.png)).
- **Эксперименты с обучением** (правила приёма записаны до запуска, [`docs/stage2_protocol.md`](docs/stage2_protocol.md)):
  - C — здоровые T1 из BRISC (половина внешних, 518) в обучении классификатора: **принят** (ансамбль «текущие + 2 новые модели»): ложные тревоги на отложенной половине BRISC 3.8% → 0.5%, на здоровых T1 теста 6/83 → 3/83, новые снимки 78% → 85% (глиомы 41% → 59%), точность теста 92.3% → 92.9%, чувствительность 98.8% → 98.6% ([`results/stage2/normals_experiment.json`](results/stage2/normals_experiment.json));
  - B — BRISC + искажения качества снимка (BigAug-подобные): **отклонён по правилу**. На BRISC Dice с контурами врачей вырос (0.784 → 0.794, кандидаты отдельно — 0.813), но на нашей валидации Figshare прироста нет (0.830 → 0.829 при пороге +0.003), macro-F1 классификации тоже не вырос. Правило записано до запуска, поэтому в итоговый ансамбль B не вошёл ([`results/stage2/v3_decision.json`](results/stage2/v3_decision.json), [`stage2b_summary.json`](results/stage2/stage2b_summary.json)).

## Этап 1: что сделано

1. **Аудит данных организаторов.** У **77%** снимков официального теста есть почти точная копия в обучающей части (корреляция ≥ 0.98 с учётом поворотов и отражений). Простой поиск похожего снимка без нейросети даёт на официальном тесте **93%**. Поэтому все модели оцениваются на собственном **групповом разбиении**: копии одного снимка, его аугментации и снимки одного пациента не попадают одновременно в обучение и тест.
2. **Классификатор** — наличие и тип опухоли (глиома / менингиома / опухоль гипофиза / нет опухоли). Сравнили 9 вариантов (архитектуры, аугментации, предобучение, разрешение, ансамбли); **по валидации выбран ResNet-50** (тест для выбора не использовался).
3. **Сегментация** (U-Net, ResNet34) — контур опухоли. Обучена на масках врачей из открытого набора Figshare (Cheng, 233 пациента). Внутри данных организаторов найдены снимки 231 из этих пациентов, маски перенесены на них.
4. **Прототип для врача** (Gradio): снимок → оценка наличия и типа → выделенная область → текстовое пояснение; пакетная проверка папки.
5. **Проверки честности и устойчивости**, независимая рецензия методики.

## Ограничения

- **Глиомы** — самый трудный класс: распознано 87.1%, Dice контура 0.70; чаще всего путаются с менингиомой.
- **Нормальные снимки** в данных — в основном другие режимы МРТ и другие источники, чем опухоли. Отличать норму от опухоли именно на T1 с контрастом из той же клиники мы проверить не можем: таких нормальных снимков нет.
- **Низкое разрешение** (≤ 256 px): точность 90.2% против 94.0% у снимков > 400 px.
- **Разбиение по пациентам** гарантировано только для снимков, связанных с Figshare (~65%); для остальных — по копиям и аугментациям.
- Анализируются отдельные 2D-срезы JPG, а не DICOM-исследование целиком. Внешняя валидация на данных другой клиники не проводилась.

## Как устроено

```
Срез МРТ → предобработка (серый, квадрат, 256×256, контраст) → классификатор ResNet-50 (есть ли опухоль, тип)
                                                            → U-Net (контур опухоли) → пояснение для врача
```
Два режима решения на честном тесте (цифры этапа 1, одиночные модели; у итогового ансамбля чувствительность 98.7% / специфичность 99.1%):
- **скрининг** (классификатор, порог 0.5): чувствительность 99.0%, специфичность 98.5%*;
- **подтверждение** (найден контур U-Net): чувствительность 93.9%, специфичность 99.7%*.
